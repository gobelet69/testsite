# Cloudflare Worker Playground

A small personal project created to experiment with **Cloudflare** and discover what can be built using its services.

The project uses a **Cloudflare Worker** with **R2 storage** to create a simple file hosting interface with authentication, file upload, download and deletion.

The main goal of this repository was simply to test Cloudflare, understand how Workers and R2 work, and explore serverless applications.

## Purpose

This is only an experimental project made for learning and testing purposes.
